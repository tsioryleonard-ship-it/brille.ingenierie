Partager l'application aux familles d'octobre

Ces familles viennent de tes ateliers en centre : l'accès est gratuit. Le premier défi démarre le lundi 2 novembre (réglage debutDefis).

Comment ça marche. Chaque famille reçoit un lien personnel avec son code. Elle n'ouvre que les pétales vécus en atelier. Les bilans restent dans son téléphone, rien n'est stocké chez toi.

Pour chacune : un nom repère (prénom ou initiale, pas de données sensibles) et les pétales vécus en atelier. Tu as déjà 10 modèles dans ton carnet (« Famille 01 » à « Famille 10 »).

Au choix :

  • le fichier gestion-des-acces.html du dossier etincelle-prive (sur ton ordinateur), ou
  • l'application, onglet « Accès ingénieure » avec ton code de 12 caractères.

Utilise toujours le même appareil, car le carnet (les clés) est gardé dedans. Garde aussi la copie carnet-familles.json.

Une ligne par famille, avec uniquement les pétales travaillés ensemble.

Deux fichiers sont téléchargés : acces.json et contenu.enc.json.

Upload files → glisser ces 2 fichiers → Commit changes. Attendre 1 à 2 minutes. Les codes ne marchent qu'après cette étape.

Ouvre le lien d'une famille sur ton téléphone, vérifie que les bons pétales s'ouvrent et que les autres restent fermés.

Ouvrir la vente aux familles hors centre

Ne commence qu'après l'étape 5 de l'onglet « L'ordre à suivre » (mentions légales et médiateur).

  • Adresse : stripe.com, avec ton courriel pro.
  • Renseigne ton activité, ton SIRET, ton IBAN et une pièce d'identité (Stripe les demande lui-même).
  • Aucun abonnement : Stripe prend environ 1,5 % + 0,25 € par paiement par carte européenne standard.

Paramètres → Informations publiques :

  • Conditions de service : …/legal.html#cgv
  • Confidentialité : …/legal.html#confidentialite

(Remplace « … » par l'adresse de ton site GitHub.)

Dans le bloc achat, un champ "lien" par offre. Sur GitHub : ouvrir config.json → crayon → coller entre les guillemets → Commit.

Dans l'espace de gestion, crée un lot de codes « vente » (par ex. 10), puis « Préparer les fichiers » et publie-les. Un code est ainsi déjà actif quand quelqu'un paie.

Avec le mode test de Stripe, vérifie le parcours jusqu'à la page « merci ».

  1. Dans config.json, mets "actif": true.
  2. Dans sw.js, augmente le numéro de version (etincelle-v14 devient etincelle-v15).
  3. Publie sur GitHub.
Tarif solidaire (19 €). Sans justificatif : la personne coche une déclaration sur l'honneur dans l'application. Tu n'as rien à vérifier.

Après chaque achat : la routine

Délai annoncé aux familles : 48 heures ouvrées. Cinq minutes suffisent.

Elle indique le courriel de l'acheteur et l'offre payée.

Carte « Après un paiement » : saisis le courriel de l'acheteur, puis clique sur le bouton pour préparer le message.

Colle-le dans un courriel à l'acheteur. Marque la famille « envoyé ».

Montant brut, date, nom de l'acheteur. Les frais Stripe se déclarent à part, en frais.

Quand il reste 3 codes, crée un nouveau lot et publie-le.

Remboursement ou litige : depuis Stripe, bouton « Rembourser ». Un litige carte coûte 20 €. Rappelle-toi la case de renoncement au droit de rétractation cochée à l'achat.
